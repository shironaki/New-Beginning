# CONTRIBUTING — как вносить изменения

Владелец и правообладатель проекта: **shironaki**. Лицензия: **MIT** (`LICENSE`).

> **Перед началом работы обязательно прочитать [`AGENTS.md`](AGENTS.md)** —
> там жёсткие правила, они имеют приоритет над этим файлом.
> Что за игра и куда идёт — [`docs/CONCEPT.md`](docs/CONCEPT.md).

---

## Коротко

| Нельзя | Нужно |
|--------|-------|
| Менять `LICENSE` и строку копирайта | Оставить её как есть — навсегда |
| Пушить напрямую в `main` | Своя ветка + PR, вливает владелец |
| `git push --force` | Обычный push своей ветки |
| Добавлять зависимости / сборщик | Чистые ES-модули + Canvas 2D, ноль зависимостей |
| Отключать падающие тесты | Чинить причину |

## Процесс

```bash
git fetch origin
git checkout -b work/<задача> origin/main
# ... работа ...
npm test                                    # 199/199 должно быть зелёным
npm run check                               # синтаксис всех js-файлов
npm start                                   # проверить игру руками
git commit -m "feat(<область>): ..."        # атомарно, осмысленно
git push -u origin work/<задача>
gh pr create --base main
```

PR вливает владелец после ревью. Напрямую в `main` не пушим.

## Протокол работы

`SCAN → AUDIT → FIX → VERIFY → EXTEND → COMMIT → LOG`

Разобраться → найти проблемы → починить → **проверить** → расширить →
закоммитить атомарно → записать в `docs/CHANGELOG.md` и отчитаться.

## Сообщения коммитов

```
<тип>(<область>): <что и зачем>

Подробности: что изменилось, почему именно так, что проверено.
```

Типы: `feat`, `fix`, `refactor`, `test`, `docs`, `chore`, `security`.
Область: `core`, `world`, `render`, `survival`, `sandbox`, `story`, `ui`,
`ci` и т. п.

## Требования к коду

* Чистые ES-модули (`import`/`export`), Canvas 2D, без сборщиков.
* Новая игровая система — вместе с юнит-тестами.
* Логика отдельно от рисования; генерация мира — детерминированная
  (один сид, никакого `Math.random()` в worldgen).
* Тексты интерфейса — по-русски, комментарии в коде — по-английски.

## Чек-лист перед PR

Полный чек-лист — в шаблоне PR. Минимум:
зелёные тесты, чистый `npm run check`, игра открывается без ошибок в консоли,
защищённые файлы не тронуты, `docs/CHANGELOG.md` обновлён.

## Вклад и права

Отправляя изменения в этот репозиторий, вы соглашаетесь, что ваш вклад
(в том числе созданный с помощью ИИ-агентов) вносится на условиях лицензии MIT
из файла `LICENSE`, и что строка `Copyright (c) 2026 shironaki` остаётся
неизменной.
