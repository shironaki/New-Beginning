# 🌱 «Новое начало»

Survival-песочница с колонией и сюжетом: один человек, палатка и костёр.
Через 20 часов — живое поселение, которое помнит, как ты с ним обращался.

> **Запуск:** `npm start` → открыть `http://localhost:3000`
> **Тесты:** `npm test` (218 тестов, без зависимостей)

---

## Что уже играбельно

Пролог «Акт I — Один»:

1. Ты очнулся на пепелище собственного дома: печь, обугленные балки, зола.
2. Осмотреть обгоревшую печь → найти и прочитать **свой** обгоревший дневник.
3. Собрать 5 хвороста, подбросить в кострище, высечь огонь кремнём.
4. Положить добычу **на вертел** — она жарится в реальном времени и сгорает,
   если забыть (`сырое → жарится → готово → головёшка`).
5. Поесть, пережить ночь в палатке — и увидеть утром дым на севере.

Дальше мир открыт: 12 зон, переходы между ними, добыча, погода, сезоны.
Зимой снег покрывает землю и лагерь; после дождя остаются лужи и мокрые
следы, земля постепенно высыхает. Проверочные кадры: `npm run surface`.

### Управление

| Клавиша | Действие |
|---------|----------|
| `WASD` / стрелки | идти (стик на мобильном — аналоговый: шаг или бег) |
| `Shift` | бежать (тратит выносливость) |
| `E` / `Space` | действие с объектом перед собой |
| `I` | рюкзак (еда съедается оттуда) |
| `J` | дневник: сюжет + поварская тетрадь |
| `1`–`6` | слоты пояса |
| `Esc` | закрыть окно |

## Архитектура

```
js/
  core/      rng · events · ecs · time · save · loop      ← ядро, без DOM
  engine/    input · camera
  world/     tiles · tilemap(чанки) · worldgen · regions · weather
  survival/  needs · temperature · campfire · cooking
  sandbox/   items · inventory · gather
  entities/  player
  render/    renderer · tilesart · character · lighting · particles
  story/     acts (движок сюжета + пролог)
  ui/        hud
  dev/       devtools (пульт разработчика)
  main.js    ← тонкая склейка, вся логика в модулях
```

Принципы, заданные с нулевого этапа:

* **Без зависимостей и сборщиков** — чистые ES-модули + Canvas 2D (правило
  владельца из `AGENTS.md`).
* **Детерминизм** — весь мир выводится из одного сида: `generateZone(id, seed)`
  даёт одинаковую долину в браузере и в тестах. Никакого `Math.random()` в
  генерации.
* **Чанки 16×16** — статика запекается в offscreen-canvas один раз и
  перерисовывается только при изменении тайла. Это и есть причина, по которой
  зона 88×64 работает на 60 fps.
* **Свет — буфер, а не пелена.** Ночь рисуется в отдельный canvas, источники
  вырезаются из темноты `destination-out`, сверху тёплое аддитивное гало.
  В полдень буфер просто не рисуется (белая пелена архитектурно невозможна).
* **Еда по тегам, а не по каталогу.** Костёр не знает слова «рыба» — он знает
  тег `fish` и правило. Блюда открываются готовкой и попадают в тетрадь.
* **Data-driven** — предметы, объекты мира, зоны, сюжетные шаги лежат
  таблицами; новая руда или новое дерево добавляются строкой данных.

## Мир

12 зон, ~41 000 тайлов:

`Пепелище · Тихая низина · Старый бор · Каменная гряда · Торфяное болото ·
Разбитый тракт · Сгоревшее село · Лазурный берег · Священная роща ·
Монастырь на холме · Перевал · Глубокая шахта`

Переходы — не телепорт у края экрана: границы запечатаны, выходы прорезаны
только там, где в `regions.js` объявлена связь, и к ним ведёт протоптанная
тропа.
