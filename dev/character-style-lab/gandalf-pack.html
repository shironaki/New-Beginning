Это уже не имитация: листы взяты из GandalfHardcore Character Asset Pack.zip, который вы положили в ветку. Каждый файл — сетка 10×7 по 80×64 (строки: Idle 5, Walk 8, Run 8, Jump 4, Fall 4, Use/Attack 6, Death 10 кадров). Тело, одежда, причёска и предмет в руке — отдельные листы, они совпадают по кадрам, поэтому здесь собираются в один спрайт в реальном времени.
