# 🛠 Режим разработчика

Пульт для быстрой проверки игры: не наигрывать часами, а за минуту посмотреть
любую зону в любую погоду, в любое время суток и года.

## Вход

1. В игре нажми **Ctrl + Shift + D**.
2. Введи пароль. По умолчанию — **`ashes2026`**.
3. Панель открывается справа. Та же комбинация закрывает и открывает её снова.
   Кнопка **«Запереть»** в самом низу выходит из dev-режима совсем.

Сменить пароль:

```bash
node tools/devpass.js "новый пароль"
```

В репозитории хранится **только SHA-256** пароля (`dev.config.json`), сам
пароль нигде не лежит.

> Честно о защите: клиент игры открыт, поэтому пароль в браузере — это замок
> от случайного игрока, а не криптографическая граница. По-настоящему пароль
> проверяется на сервере: `serve.js` не примет заметку без него.

## Что умеет панель

| Раздел | Возможности |
|---|---|
| **Время** | ползунок на все 24 часа, пресеты «Рассвет / Утро / Полдень / Закат / Ночь», −1 ч / +1 ч, ускорение времени ×1 … ×120 и «стоп» |
| **День и сезон** | −1 / +1 / +7 дней, прыжок в любой сезон (весна 1, лето 29, осень 57, зима 85) |
| **Погода** | все семь состояний одной кнопкой, «Зафиксировать» (погода не сменится сама), ползунок направления ветра |
| **Локации** | кнопка на каждую зону — мгновенный переход на её точку входа |
| **Герой** | ползунки сытости, тепла, усталости, здоровья и духа; пресеты «Всё в норму» / «На грани» / «Промок»; проход сквозь стены; скорость ×1 ×2 ×4 |
| **Предметы** | наборы «Инструменты / Еда / Топливо / Материалы» и строка выдачи `log 5` |
| **Отладка вида** | сетка тайлов, хитбоксы пропсов и героя, статистика (зона, координаты, чанки, частицы, FPS-данные), зум |
| **Заметки** | отметить место и описать, что не так |

## 📍 Заметки — как показать мне, что именно поправить

1. В панели: **«📍 Отметить место»**.
2. Курсор станет перекрестием — **кликни по тому месту на экране**, где
   проблема (Esc — отмена).
3. Напиши, что не так и как должно быть. **Ctrl+Enter** — отправить.

Заметка уезжает в репозиторий, в `docs/notes/`, и состоит из двух файлов:

- `.md` — текст, зона, мировые координаты и тайл, день, время, сезон, погода,
  зум и **готовая команда**, чтобы я воспроизвёл ровно этот кадр:
  `node tools/scene.js --zone … --at … --hour … --weather … --zoom …`;
- `.png` — скриншот ровно того, что было на экране в момент заметки.

Если игра открыта не через `node serve.js` (а просто как файл), заметка
скачается в загрузки как `.json` — ничего не теряется, просто перешли её мне.

Писать в `docs/notes/` руками тоже можно: любой `.md` в этой папке я прочитаю.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+D` | открыть / закрыть панель |
| `Esc` | отменить режим «отметить место» |
| `Ctrl+Enter` | отправить заметку из формы |
