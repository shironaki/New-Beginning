# 🛠 Режим разработчика

Пульт для быстрой проверки игры: не наигрывать часами, а за минуту посмотреть
любую зону в любую погоду, в любое время суток и года.

## Вход

1. В игре нажми **Ctrl + Shift + D**.
2. Введи пароль. По умолчанию — **`nachalo2026`**.
3. Панель открывается справа. Та же комбинация закрывает и открывает её снова.
   Кнопка **«Запереть»** в самом низу выходит из dev-режима совсем.

Сменить пароль:

```bash
node tools/devpass.js "новый пароль"
```

В репозитории хранится **только SHA-256** пароля (`dev.config.json`), сам
пароль нигде не лежит.

> Честно о защите: клиент игры открыт, поэтому пароль в браузере — это замок
> от случайного игрока, а не криптографическая граница. По-настоящему пароль
> проверяется на сервере: `serve.js` не примет заметку без него.

## Что умеет панель

| Раздел | Возможности |
|---|---|
| **Время** | ползунок на все 24 часа, пресеты «Рассвет / Утро / Полдень / Закат / Ночь», −1 ч / +1 ч, ускорение времени ×1 … ×120 и «стоп» |
| **День и сезон** | −1 / +1 / +7 дней, прыжок в любой сезон (весна 1, лето 29, осень 57, зима 85) |
| **Погода** | все семь состояний одной кнопкой, «Зафиксировать» (погода не сменится сама), направление ветра, влажность земли 0–100%, «Сухо» / «После ливня» |
| **Локации** | кнопка на каждую зону — мгновенный переход на её точку входа |
| **Герой** | ползунки сытости, тепла, усталости, здоровья и духа; пресеты «Всё в норму» / «На грани» / «Промок»; проход сквозь стены; скорость ×1 ×2 ×4 |
| **Предметы** | наборы «Инструменты / Еда / Топливо / Материалы» и строка выдачи `log 5` |
| **Отладка вида** | сетка тайлов, хитбоксы пропсов и героя, статистика (зона, координаты, чанки, частицы, FPS-данные), зум |
| **Заметки** | отметить место и описать, что не так |

## 📍 Заметки — как показать мне, что именно поправить

1. В панели: **«📍 Отметить место / область»**.
2. Курсор станет перекрестием:
   - **клик** — отметить точку;
   - **зажать и протянуть мышь** — выделить **область** (рамка видна прямо
     во время выделения, в углу показан её размер).
   - `Esc` — отмена.
3. Напиши, что не так и как должно быть. **Ctrl+Enter** — отправить.

К заметке прикладывается **кадр с нарисованной меткой**: точка — красное
перекрестие, область — красная рамка. Я вижу ровно то, что ты имел в виду.

### Куда она попадает

| Где ты играешь | Что происходит |
|---|---|
| через `node serve.js` (в том числе живое превью Arena) | заметка **сразу** пишется в репозиторий: `docs/notes/…md` + `…png` |
| GitHub Pages, или файл с диска | сервера нет — заметка **копится в очереди в браузере**; ничего не скачивается |

В разделе «Заметки» видно счётчик очереди и три кнопки:

- **«Отправить очередь»** — попытаться ещё раз (например, когда ты зашёл
  через dev-сервер); очередь отправляется и сама, каждый раз когда открываешь
  панель;
- **«Выгрузить файлом»** — **один** файл со всеми заметками сразу
  (`notes-ГГГГ-ММ-ДД-N.json`), а не россыпь файлов по одному на баг;
- **«Очистить»** — выбросить очередь.

Выгруженный файл превращается в обычные заметки одной командой:

```bash
npm run notes -- ~/Downloads/notes-2026-10-06-7.json
node tools/notes-import.js bundle.json --dry   # только посмотреть, что внутри
```

В очереди держится до 40 заметок, кадр ужимается до 1280 px по ширине, чтобы
браузеру было где их хранить.

Каждая заметка — пара файлов:

- `.md` — текст, зона, **точка или область** (в пикселях и в тайлах), день,
  время, сезон, погода, зум и готовая команда, чтобы я воспроизвёл ровно этот
  кадр: `node tools/scene.js --zone … --at … --hour … --weather … --zoom …`;
- `.png` — кадр с меткой.

Писать в `docs/notes/` руками тоже можно: любой `.md` в этой папке я прочитаю.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+D` | открыть / закрыть панель |
| `Esc` | отменить выделение / режим пометки |
| `Ctrl+Enter` | отправить заметку из формы |

## Проверка погоды и сезонов (этап 56)

- **Зима:** выбери сезон — земля обновится сразу, даже при остановленных
  часах. Верни весну — зимний слой исчезнет без перезагрузки игры.
- **Дождь:** при обычном ходе игры почва намокает постепенно (до насыщения
  за 45 игровых минут дождя; в грозу быстрее). При остановленных часах
  влажность тоже стоит. Чтобы не ждать, нажми **«После ливня»**.
- **После дождя:** выбери «Ясно» — лужи не исчезнут сразу. Часы двигаются —
  земля высыхает. «Сухо» мгновенно убирает последствия для сравнения.
- **Слякоть:** зима + «После ливня». В шахте эти наружные эффекты отключены.

Новые заметки включают день, минуты, числовой сид и влажность. В старых
заметках история влажности отсутствует; `--wet 0.85` задаёт проверочное
состояние после дождя, а не восстанавливает неизвестную историю погоды.

```bash
npm run surface   # 9 кадров в .artifacts/surface/
node tools/scene.js --zone ashfall --at 804,1104 --day 57 --hour 20 --weather rain --wet 0.85 --zoom 2.4
```

Сид, геометрия карты и коллизии от этих настроек не меняются. Снежный слой
сезонный, влажность общая для наружного мира; физика стока и толщина снега
пока не моделируются.
