# 📍 Заметки с места

Сюда попадают заметки, поставленные прямо в игре: **Ctrl+Shift+D** → пароль →
раздел «Заметки для правок» → «📍 Отметить место» → клик по нужной точке на
экране → описание.

Каждая заметка — это пара файлов:

- `ГГГГ-ММ-ДД-NNN-<зона>-<кратко>.md` — текст, зона, координаты, день, время,
  сезон, погода, зум и **готовая команда**, чтобы я воспроизвёл этот самый кадр:
  `node tools/scene.js --zone … --at … --hour … --weather … --zoom …`
- одноимённый `.png` — кадр ровно в тот момент, когда заметка была поставлена.

Писать сюда руками тоже можно: любой `.md` в этой папке я прочитаю.


## Как посмотреть ВСЕ пометки разом

Три пути, от самого быстрого к самому надёжному:

1. **В игре.** `Ctrl+Shift+D` → раздел «Заметки для правок» → **«Выгрузить все
   файлом»**. Один JSON со всеми заметками очереди (текст, координаты, день,
   время, погода, зум, кадр) — работает даже без dev-сервера и даже если Git
   недоступен. Рядом кнопки «Отправить очередь» (повторить доставку) и
   «Очистить доставленные».
2. **В репозитории.** Все доставленные заметки лежат здесь, парами
   `.md` + `.png`: `ls docs/notes | grep -v README` — и читаются как обычный
   текст, `grep -l "неприемлемо" docs/notes/*.md` и т. п.
3. **Списком со статусами.** `node tools/notes-list.js` печатает таблицу
   `NNN · дата · зона · текст · есть ли кадр` по всем `.md` этой папки.

Счётчик в панели («Ожидают Git: 2 · в архиве: 2») считает **локальную очередь
браузера**, а не репозиторий: «Ожидают» = ещё не подтверждены Git, «в архиве» =
всё, что лежит в очереди браузера. Если число «Ожидают» не уходит, а `git push`
отбит (`rejected … fetch first`, ветка разошлась с origin), заметки никуда не
пропали — они уже в локальном коммите. Тогда надо либо `git pull --rebase` и
нажать «Отправить очередь», либо просто выгрузить всё файлом (пункт 1).
