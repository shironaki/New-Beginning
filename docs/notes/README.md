# 📍 Заметки с места

Сюда попадают заметки, поставленные прямо в игре: **Ctrl+Shift+D** → пароль →
раздел «Заметки для правок» → «📍 Отметить место» → клик по нужной точке на
экране → описание.

Каждая заметка — это пара файлов:

- `ГГГГ-ММ-ДД-NNN-<зона>-<кратко>.md` — текст, зона, координаты, день, время,
  сезон, погода, зум и **готовая команда**, чтобы я воспроизвёл этот самый кадр:
  `node tools/scene.js --zone … --at … --hour … --weather … --zoom …`
- одноимённый `.png` — кадр ровно в тот момент, когда заметка была поставлена.

Писать сюда руками тоже можно: любой `.md` в этой папке я прочитаю.
